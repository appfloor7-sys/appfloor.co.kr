# GroupKey — 공식 홈페이지

회사 계정·비밀번호·인증 정보를 팀 단위로 관리하는 GroupKey 소개 사이트입니다.

## 구성
- `index.html`: 반응형 한국어 랜딩 페이지
- 외부 프레임워크 및 빌드 과정 없이 정적 HTML/CSS/JS로 동작합니다.
- Vercel 프로젝트에서 이 저장소를 연결하면 정적 사이트로 배포할 수 있습니다.

## 콘텐츠 기준
제품 기능 설명은 `appfloor7-sys/account` 저장소의 README에 기재된 구현 내용을 기준으로 작성했습니다.
무료 플랜은 대표 포함 활성 사용자 5명까지로 안내하며, 유료 요금은 확정된 결제 정책이 아니므로 금액을 표시하지 않았습니다.
보안 문구는 구현 기능에 한정하며, 외부 보안 인증이나 독립적인 침투 테스트 완료를 주장하지 않습니다.
